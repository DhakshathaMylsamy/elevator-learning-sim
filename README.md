# Elevator Lab

A beginner-friendly interactive elevator simulation website to learn how elevator parts work together.

## Features

- Interactive floor simulation
- Beginner explanations of major elevator parts
- Simple UI with dark neon styling
- Demo animation for a complete ride cycle
- Responsive layout for desktop and mobile

## Run locally

From this folder, run:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Files

- `index.html` – main app structure
- `styles.css` – neon UI styling
- `script.js` – elevator simulation logic and explanations
